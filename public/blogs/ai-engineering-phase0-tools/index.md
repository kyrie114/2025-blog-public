Phase 0 一共 12 课，不是要一次全装。下面这张图只回答两件事：**干什么用**、**什么时候才需要碰**。

## 核心六件

| 工具 | 干什么用 | 什么时候用到 |
| --- | --- | --- |
| Git | 给每次实验、每份代码留记录 | 第一天起。日常就 `add / commit / push`；试错开分支 |
| GPU | 把矩阵乘法从 CPU 挪到显卡 | 本地有卡用 `nvidia-smi`；没有卡用 Colab / 云 GPU。入门课 CPU 够用 |
| API | 发请求、拿回复。密钥不当代码提交 | 调 OpenAI / 自建服务时。先会 `GET/POST` + 环境变量 |
| Jupyter | 实验室工作台：先试再搬进脚本 | 画图、看张量、快速验证。能跑通就迁出 notebook |
| venv（用 uv） | 每个项目一份依赖，互不踩 | 装 PyTorch 之前。全局 pip 是环境腐烂的起点 |
| Docker | 「在我机器上能跑」变成可搬运镜像 | 复现训练、上 GPU 集群、固定 CUDA 版本时 |

## 另外六件（用到再学）

| 工具 | 干什么用 | 什么时候用到 |
| --- | --- | --- |
| 编辑器 | 跳转、终端、格式化、AI 补全 | 每天写代码。先把 Python / 保存即格式化配好 |
| 数据 | 数据集、缓存、目录约定 | 开始训练或下载权重。模型和大数据不要进 git |
| 终端 | 管道、重定向、任务控制 | 跑脚本、看日志、连远程。比点按钮可重复 |
| Linux | 权限、进程、路径、SSH | WSL / 云主机上几乎所有课。Windows 本机也建议 WSL2 |
| 调试 | 断点、打印张量、看哪一层炸了 | loss 变 NaN、形状对不上、比 CPU 还慢的时候 |
| 预检脚本 | 一键回答「我能不能开下一课」 | Day1 结束时跑一次，换机器再跑一次 |

## 怎么用这张图

- **现在**：Git + uv/venv + 预检。这三件不过关，后面全是噪音。
- **有卡再碰 GPU**；没有卡就 Colab，别在驱动上耗第一周。
- **Jupyter 只做草稿**，能复现的结果写进 `.py`。
- **Docker 不是入门门槛**。本地 uv 环境能跑通，再谈镜像。

对应课程：`phases/00-setup-and-tooling/`，01 环境 → 12 调试。按需点开，不必按表全做。
